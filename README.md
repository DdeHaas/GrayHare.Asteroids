# GrayHare.Asteroids

## Overview

GrayHare.Asteroids is a classic arcade space shooter built with [`GrayHare.GameEngine`](https://github.com/DdeHaas/GrayHare.GameEngine). Pilot your ship through an asteroid field, rotate and thrust in any direction, blast rocks apart, dodge UFO fire, and survive as long as possible while chasing a high score.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Start game | Any key | Start |
| Thrust | `Up`, `W` | D-pad up|
| Rotate left | `Left`, `A` | D-pad left|
| Rotate right | `Right`, `D` | D-pad right|
| Fire | `Space` | L1 / R1 |
| Pause | `P` | Start |
| Mute audio | `M` | — |
| ' (grave} | `Debug visuals On / Off` | — |
| Exit | `Escape` | Select |

## Running from the repository

```
dotnet run GrayHare.Asteroids
```

## Requirements

- [.NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- [SFML.Net](https://www.nuget.org/packages/SFML.Net) 3.0.0
